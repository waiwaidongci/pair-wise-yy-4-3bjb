# 水下考古潜水记录 · 出水晾护交接台

直接打开 `index.html` 使用。

## 功能

- **平面图标记**：点位、类型、潜次、保存状态（原有功能保留）。
- **出水登记**：每条登记出水时刻、材质（取标记类型）、含水率、当前容器。
- **待办看板**：风险与待办统一按剩余时限排序，超时自动进入风险清单，每秒刷新倒计时。
- **保管员交接**：接手须核对当前容器与上一步时间；换容器保留旧容器段并重算风险；可复测含水率。
- **晾护档案**：每个出水件的容器段（旧段封存保留）与交接记录，支持导出 JSON。

## 判定规则（js/rules.js，阈值集中在文件头部）

- 木质件离水 **30 分钟**未入保湿箱 → 进风险清单。
- 陶片含水率 **＞18%**：先阴干，**不能进恒湿柜**（交接换容器时拦截）。
- 陶片出水后 **60 分钟**内应转阴干架（宽限，可调）。

## 结构（判定 / 档案 / 界面各自独立承载）

- `js/rules.js` — 判定层：纯函数规则与阈值，不碰存储和界面。
- `js/archive.js` — 档案层：localStorage 存取、容器段、交接日志。
- `js/app.js` — 界面层：渲染与交互。
- `tests/care.test.js` — 判定与档案层测试：`node tests/care.test.js`
